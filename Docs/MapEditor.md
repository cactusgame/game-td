# 地图编辑器首版

地图编辑器现已扩展为关卡编辑器，波次、出怪组、金币覆盖及试玩的当前使用说明见 [关卡编辑器](LevelEditor.md)。本文保留地图布局和原始纯地图试玩说明。

## 打开和使用

Unity 菜单 **Game → 关卡编辑器**，切换“地图布局”。仓库已包含示例地图、素材目录和独立试玩场景。
如果示例资源引用损坏，可运行 **Game → 地图工具 → 安装示例内容**；该操作重建素材目录引用，不覆盖已有示例地图或已有试玩场景。

1. 新建地图，在右侧设置列数、行数、格宽、格高和原点，点击“应用设置”。尺寸以格数表示，实际长度为格数乘格宽高；支持非正方形格子和非居中原点。
2. 左侧“素材与工具”统一平铺所有缩略图。直接点击草地、泥地、道路、河流、岩石或树木图片，即切换到对应地形笔刷，无需另外选择绘制工具。按住左键绘制，一笔对应一次撤销。选中项以金色边框高亮，悬停可查看用途。打开“显示实际通行”，绿色可通行，红色受地形、建筑或墙体阻挡。
3. 点击“英雄出生”或“敌人入口”图标放置标记。英雄出生位置唯一；可以有多个入口。青色圆点为英雄，橙色为入口。选中标记可修改名称。
4. 直接点击示例箭塔或主堡缩略图，再在地图上放置。点击“移动”图标可拖动建筑、标记及墙节点；建筑落点无效时恢复原位。建筑占地用蓝框表示，选中后黄色高亮。
5. 点击“城墙”缩略图，再依次点击节点，每两次点击形成一条稳定墙边。点击已有节点可连接到已有墙网，Esc 结束当前折线。移动节点会更新关联墙边，删除节点会删除关联边。交叉处必须显式共用同一个节点；未共享节点的交叉会报告错误，不会悄悄导出断开的拓扑。节点代表敌台底座中心，自由端不再向所在格子的边缘延长。
6. 选择后按 Delete 删除对象；也可点击左侧删除按钮。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。键盘快捷键在画布获得焦点时生效，不干扰文本输入。
7. Q 选择平移工具后左键拖动，W 切换移动；右键取消当前选择和未提交的编辑，并切换到移动工具；也可中键拖动或空格加左键临时平移。滚轮围绕鼠标位置缩放，“适配画布”恢复全图视野。“显示网格”独立控制网格线，默认隐藏。
8. 保存生成地图源 JSON，可以保留未完成的草稿。重新打开保留地图 ID、对象 ID、地形和墙网。导出地图必须通过校验。
9. 点击“校验”，再点击具体问题定位格子或对象。缩小地图保留重叠格子的地形；标记和墙节点保持原有世界坐标，越界内容需手动修复。
10. 点击“独立试玩”，从当前工作副本创建隔离场景。试玩无需先覆盖源文件。

画布上方并排提供“显示/隐藏 Tile 网格”和“显示/隐藏实际通行”按钮，开启时高亮；两项可独立切换并在脚本重载后保留状态，不修改地图文档。

首版没有区域编辑。草地、泥地、道路默认允许建设；河流、岩石、树木禁止建设。
设施与墙体再提供占地限制。水不阻挡射击，岩石和树木提供射击阻挡语义；当前原型没有射线武器系统，这一语义尚不参与攻击结算。

## 独立试玩与游戏加载

试玩使用独立 `BattleSession` 和 ECS World。WASD / 方向键移动英雄；选择 Build tower 后点击地图建设，选择 Remove 后点击建筑或墙体拆除；Restart 恢复地图初始状态。Exit 返回编辑。

试玩中只读载入导出的地图定义，设施运行状态、单位位置和生命单独保存。建设提交先检查地形、占地、标记和单位净空，失败不留下设施；成功后在下一次模拟步之前同时更新空间索引、导航和碰撞。导航不是唯一的移动约束：英雄和游走怪物也不能穿过障碍。

试玩快照及场景写入 `Assets/Generated/MapPlaytest/`，已在 Git 中忽略。源地图和编辑历史不受试玩影响；编辑历史跨脚本重载保留，文件重新打开建立新的历史。
退出后恢复先前的 Play Mode 启动场景，原有 `BattlePrototype` 场景保持不变。

游戏加载入口为 `Assets/Scenes/Development/MapPlayground.unity` 中的 `MapPlayController`。
把该组件的 `Map Json` 引用换成导出的 JSON，即可直接在 Play Mode 加载另一张地图。
加载使用序列化 TextAsset 引用，不依赖外部美术目录或桌面绝对路径。

首版试玩每个入口生成一只怪物；单位属性仍读取现有 `battle.json`，入口不会引用原型压力测试的千只怪物配置。该生成方式用于地图验证，正式波次调度留给关卡模块。

## 内容与范围

- 示例地图：`Assets/Content/Maps/Example/example.map.json`。
- 示例素材：`Assets/Content/Maps/Shared/Sprites/`，复制自本次指定的 `game-td-arts/tiles`。这些原始图片带透明边缘，并非正式无缝地形。后来修改为“Assets/Content/Maps/ArtV2下的Atlas“
- 素材映射：`Assets/Content/Maps/Shared/MapVisualCatalog.asset`。替换 Sprite 引用即可换美术，不改变逻辑占地。
- 当前地表、树石、墙材质与门图使用 `Assets/Content/Maps/ArtV3/`。`Wall Masonry` 提供立面石材，`Wall Walkway` 提供独立墙顶铺地，分别按墙长/高度和世界地面坐标铺设。`Wall Body Region` 为未提供石材时的旧素材回退，建筑仍保留原示例。
- 城墙制作尺寸：同一资产的 `Wall Dimensions` 统一墙宽、敌台半径、墙顶高度、女墙和垛口尺寸，相对于较小的地形格长。它们属于本轮表现制作参数，不改变现有导航阻挡。
- 2026-10-22 的城墙连接、铺地与遮挡调整，以及本轮验证边界，见 [城墙表现说明](WallPresentation.md)。
- 建筑占地规则：`Assets/Content/Maps/Shared/facilities.json`。箭塔 1×1、主堡 2×2 是示例内容，不是长期数量或尺寸限制。
- 格式版本：地图 JSON 的 `schemaVersion = 1`，不是对局运行版本。

示例建筑具有预放、占地、运行建设与拆除能力，尚未接入攻击、升级、费用、经济产出或建筑承伤。墙体支持直线与折线、显式节点连接、稳定墙边身份、城门和拆除，尚无承伤、升级和自动交叉切分。墙图像分片仅用于绘制，不改变墙网身份。
首版墙体导航采用保守网格投影，窄缝可能被视为不可通行；这不是任意角度精确导航的最终实现。
允许无步行路径的地图，不在编辑器提前否决未来破墙玩法。地图净空按当前英雄和怪物半径额外校验。
V2 地面按 16×16 格合并 Mesh；障碍、建筑使用 Sprite，墙身和连接底座使用共享投影的程序化 Mesh。未做百万格性能或移动端验收。新美术、自然道路与 72×48 示例的说明见 [地图美术 V2](MapArtV2.md)，工具栏“美术示例地图”可直接打开。

## 代码阅读路径

1. `Assets/Game/Tools/MapAuthoring/Editor/MapEditorWindow.cs`：窗口入口，组织编辑、校验、保存、导出和试玩。
2. `Assets/Game/Tools/MapAuthoring/Core/MapEditSession.cs`：工作文档、整笔操作历史、保存修订和重载恢复。
3. `Assets/Game/Gameplay/Maps/Domain/Definitions/MapLayout.cs`、`MapDefinition.cs`：可编辑初始描述与经过验证的只读定义。
4. `Assets/Game/Gameplay/Maps/Domain/Rules/`：共享占地、门洞、墙网投影与带定位信息的校验。
5. `Assets/Game/Gameplay/Construction/Application/Sessions/MapConstructionState.cs`：运行布置与空间提交协调；墙与门由 `Fortifications/Domain/Aggregates/WallNetwork/WallNetwork.cs` 独占，地图快照按需从聚合导出。
6. `Assets/Game/Tools/MapPlaytest/Unity/MapPlayController.cs`：独立对局加载和逐帧入口；`Application/Sessions/MapPlaySession.cs` 完整提交空间变更后才推进模拟。
7. `Assets/Game/Gameplay/Battle/Simulation/Systems/TerrainCollisionSystem.cs`：移动后、接触结算前完成连续圆形占位检查。

编辑调用链：画布输入 → 墙网连接时调用 `WallNetwork.TryConnect` → 工作副本 → `MapEditSession.Commit` → 文档快照 → 画布。
试玩调用链：文档副本 → JSON → `MapDefinition` → `MapPlaySession` → `MapConstructionState` / `MapBattleDefinitionSource` → `BattleSession` → ECS → 单位快照和地图视图。

## 城门

城门已支持任意墙向、同墙多门与整数 Tile 尺寸。选择“城门”点击空位新增，已有门只选中；用“移动”沿墙拖动。右侧配置为整数门框宽度和门洞净宽，默认 4 / 2 Tile。试玩按独立门 ID 开关，拒绝覆盖单位的关门。

工具栏“城门示例地图”包含横墙多门、斜墙和纵墙门。操作、素材、数据模型、旧地图调整和代码入口见 [城门说明](Gates.md)。
