# 怪物死亡与延迟移除

统一配置：`Assets/Content/Combat/Prototype/unit-death-settings.asset`。

在 Unity Project 中选中此资源，直接修改 Inspector：

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| Animation Seconds | 0.6 秒 | 完整死亡动画的播放时长 |
| Corpse Hold Seconds | 1.5 秒 | 动画结束后保留倒地姿势的时长 |

默认从首次显示死亡状态起约 2.1 秒后移除。停留设为 0 时，动画播完就移除。两种怪物共用同一个配置；重新导入动作资源不会覆盖已修改的时长。

哥布林和疾跑怪各增加 4 帧死亡动画（2×2，从上到下、从左到右），资源位于各自 Sprites 目录下的 `goblin-death.png`、`runner-death.png`，帧引用保存在原有 `*-actions.asset` 的 Death 数组中。

生命归零时 ECS 已停止其移动和接触结算，表现层立即隐藏血条、播放倒地动画，再停留并销毁 GameObject。ECS 的死亡实体/快照仍保留至重启，BattleView 记录已移除 ID，防止下一帧重新生成尸体。重启会清除旧视图、死亡计时和已移除 ID。计时使用模拟时间，暂停时冻结。

死亡图通过内置 image_gen 制作，以原有角色动作图为参考。两套提示词共用的规格是：相同手绘卡通角色；透明正方形图，2×2 共四帧；致命踉跄、跪倒侧倾、向侧面倒下、闭眼静止侧躺；全程保持比例、保留足够透明留白；无地面、阴影、血液、文字、格线或残影。哥布林保留绿皮、棕色破衣与带钉木棒；疾跑怪保留橙红皮肤、大尖耳、米色破围巾与爪。

验证：Unity 编译通过，编辑器测试 23 项全部通过。Play Mode 验证两种怪物从 Death_0 开始，停留时保持 Death_3，约定时间后 GameObject 总数从 11 减至 9，重复渲染没有重建死亡怪物；重启后恢复 11 个单位视图。验证后已退出 Play Mode。
