# 关卡编辑器

## 使用入口

Unity 菜单 **Game → 关卡编辑器**。地图布局和波次配置统一在此窗口编辑，原“地图编辑器”重复菜单已移除。

窗口上方切换“地图布局”和“关卡与波次”。点击“三波关卡示例”可打开
`Assets/Content/Levels/Example/citadel.level.json`，然后查看第二波：同一个入口先出主力，4 秒后增援；骷髅继承关卡的 4 金币，但第二波单独覆盖为 2 金币。

旧地图打开后，在“关卡与波次”点击“将当前地图升级为关卡”。转换后保存会选择新的 `.level.json` 文件，保留原地图。新建关卡允许先保存没有波次的草稿，导出和试玩必须通过完整校验。

## 编辑内容

- 关卡：稳定 ID、名称、初始金币、按怪物 ID 设置的击杀金币覆盖。
- 波次：名称、开始方式、等待时间、完成奖励、提前开波开关及固定奖励、本波击杀金币覆盖。
- 出怪组：稳定 ID、地图出生口、怪物内容 ID、数量、起始延迟、出生间隔、备注。同一出生口可有多个组，各组独立计时和重叠。
- 波次支持新增、复制、删除、上下移动；出怪组支持新增、复制、删除。复制会产生新 ID；排序保留原 ID。
- 时间轴按出生口归组，条带起点是起始延迟，终点是最后一只出生时间。零间隔允许同时出怪。
- 统计显示本波数量、各怪物数量、出怪时长、预计击杀金币、完成奖励，以及含初始金币的累计可获得收入。累计值不扣消费、不计提前奖励，不代表当前余额。

金币使用 **波次覆盖 → 关卡覆盖 → 怪物默认**。勾选覆盖后允许填写 0；关闭覆盖才表示继承。界面显示最终值及来源。金币在怪物出生时绑定到实例；提前开启后续波次不会改变已经出生怪物的掉落。

默认击杀金币来源为 `Config/EnemyRewards.json`，按稳定怪物 ID 配置。修改后运行现有脚本：

```powershell
python Tools/ContentConfiguration/export_config.py
```

脚本将其与 `Config/GameContent.xlsx` 一并校验、生成运行时 `battle.json`，并纳入内容版本。未配置的怪物默认 0；当前示例两种怪物均为 5，这只是起始数值。

## 波次和试玩语义

开始方式有：手动开始、上一波开始后计时、上一波完成后计时。首个试玩波次的自动等待从本局时间 0 起算。自动定时方式可形成重叠波次；“允许上一波未清完时手动开波”控制玩家手动提前开始。

主界面“独立试玩”从第一波启动；每波“从本波试玩”跳过之前波次，不生成之前的怪物、不补发收入，使用关卡初始金币。测试金币可在工作副本修改初始金币，再撤销恢复。

试玩 HUD 显示真实总波次数，提供“开始下一波”。手动开波仍需满足前波已完成或允许提前的条件。允许提前且尚未到自动启动时间的后续波次发放一次固定提前奖励；首个试玩波次不发。

所有出怪组完成生成称“出怪结束”，仍有存活敌人时不算“波次完成”。本波全部敌人死亡后发放一次完成奖励。所有波次完成后胜利；主堡被摧毁失败，同步发生时失败优先。重启重置出怪、奖励收据、金币和战斗 World。

当前实际玩法仍为动态寻路并攻击主堡。尚未增加固定路线、漏怪扣生命、可用塔白名单或等级限制。怪物选择来自当前 BattleDefinition 实际加载的两种敌人；内容库中未接入战斗的类型不会作为可用选项。

## 数据和状态归属

`.level.json` 是带 `documentType = "level"`、`schemaVersion = 1` 的关卡包，包含原版地图与关卡配置。地图格式仍为 schemaVersion 1。地图和波次统一做原子保存、撤销重做及脚本重载恢复。源文档可保存草稿；导出和试玩先校验地图、出生口和怪物引用、数量、时间、覆盖重复及金币溢出。

领域层不引用 Unity、地图或 ECS：

1. `Gameplay/Encounter/Domain/Definitions/LevelLayout.cs`：创作数据；`LevelDefinition.cs` 校验并隔离副本，提供金币继承规则。
2. `Gameplay/Encounter/Domain/Aggregates/LevelEncounter/LevelEncounter.cs`：波次进度、出怪名额、单位所属波次与出生时金币的唯一拥有者。
3. `Tools/MapPlaytest/Application/Adapters/LevelDefinitionFactory.cs`：连接地图入口和已加载怪物的应用边界，校验最大可能收入。
4. `Tools/MapPlaytest/Application/Sessions/MapPlaySession.Levels.cs`：在模拟步边界协调出怪，读取死亡事实，向现有经济账户结算，再判胜负。生命与位置仍归战斗模拟，金币与入账去重收据归 `ResourceAccount`。
5. `Battle/Contracts/Ports/ILevelEnemySimulation.cs`：生成指定敌人并返回稳定单位 ID。ECS 实现沿用现有净空和寻路规则。
6. `Tools/MapAuthoring/Editor/LevelEditorPanel.cs`：创作界面；`Core/MapEditSession.cs`：地图和关卡共用的文档历史；`Infrastructure/Maps/Serialization/LevelJson.cs`：单文件序列化。

旧的纯地图试玩继续使用原两波防守配置，旧场景和测试无需迁移。正式关卡包使用新的任意波次调度。
