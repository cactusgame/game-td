# 城墙几何与材质调整（2026-10-22）

本轮只调整编辑器和游戏共用的城墙表现。未修改地图文档、节点 ID、墙边 ID、导航格长、移动碰撞或建筑占地规则。现有地图重新打开即可使用新表现，无需迁移。

## 已实现的结构

- 节点保持为敌台底座中心；取消向端点格边缘延伸自由端。
- 墙身、敌台、墙顶、女墙和垛口共用 `MapVisualCatalog.WallDimensions` 的制作尺寸。
- 敌台改为程序化多边形底座，根据所有邻接方向切出墙体接口。墙身在同一连接弦结束，不再用固定缩进配合独立图片遮盖接缝。
- 相邻墙顶与敌台顶采用相同高度与世界铺地坐标。横、纵及斜向墙共用这套生成流程；内外转角由邻接方向确定。夹角较小时，在邻接墙长允许的范围内增加敌台半径以容纳开口。
- 连接处的端面和女墙封口被移除，保留连通的顶面。垛口按固定长度和间隔生成，尾部截取，不按分片数量整体缩放。
- 立面 UV 由实际墙长与高度生成，墙顶独立按世界地面坐标铺设。纹理在重复边界处裁切，避免单个三角形跨越图集重复边界导致图案拉伸。
- 表面按地面深度带裁切，墙体与敌台片段统一排序。后侧立面、顶面和前侧女墙可以独立进入绘制顺序，不再把整座敌台作为一张前后关系不可分的 Sprite。
- 运行时相同纹理的墙片段共享材质，材质随整张地图视图释放。

## 素材与调节入口

`Assets/Content/Maps/Shared/MapVisualCatalog.asset`：

- `Wall Masonry`：墙面及敌台立面石材。
- `Wall Walkway`：独立墙顶铺地。目前沿用现有 limestone 图片，和立面分别取样，可单独换成新的铺地素材。
- `Wall Dimensions`：墙宽、墙顶高度、敌台半径、女墙厚度、垛口间距和材质重复长度，单位相对最小地形格长。

旧的 `Wall Corner`、`Wall End` 图片引用仍保留，避免丢失既有资源引用；本轮实体敌台不再用它们拼接。素材面板缩略图仍可使用旧墙图，不改变制作工具操作。

## 代码入口

1. `Assets/Game/Gameplay/Maps/Unity/Views/MapWallGeometry.cs`：共同尺寸、邻接方向、敌台轮廓和连接弦。
2. `MapRaisedWallPresentation.cs`：墙身、走道、女墙和垛口。
3. `MapWallNodePresentation.cs`：端部和转角敌台，按连接方向开口。
4. `MapWallSurfaceBuilder.cs`：材质坐标、纹理边界裁切、地面深度分片与 Mesh 数据归并。
5. `MapSceneSprites.cs`：编辑器及游戏共用的表现列表和排序。
6. `MapWorldView.cs`、`MapWallMeshView.cs`、`MapWallMaterialLibrary.cs`：运行时 Mesh、排序与资源生命周期。

输入仍经过原有编辑会话提交节点和边；生成器只读取地图副本，不改变墙网状态。

## 本轮验证范围

只进行编译、既有城墙基础测试以及新增的接口/数据契约检查。用户明确将逐场景体验验收放在后续：本轮没有运行横纵斜墙对比、拖动端点的视觉验收、角色前后遮挡走位、贴墙、绕敌台或窄口通行验收。

Unity 6000.6.4f1 编译通过。4 项城墙基础测试与 2 项新增接口/数据契约测试通过；运行时 Mesh 生成与释放在共享材质调整后再次检查通过。这些结果不代表视觉体验已经验收。

橙色通行覆盖仍来自原有保守网格，斜墙不可通行范围不会因为这次表现调整自动缩小。极短墙段、极尖转角及大规模墙网的最终外观与开销仍需后续体验反馈。
