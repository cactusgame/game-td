# 城墙纹理教学演示

双击 `index.html`，用 Chrome 或 Edge 打开即可。无需启动 Unity、安装依赖、联网或启动本地服务。
复制给别人时，请复制整个 `WallTextureDemo` 文件夹，保留 `demo.js` 和 `textures/`。

建议演示顺序：

1. 将“表面显示”切换为“纯色”，从步骤 0 依次点击到 4，观察形状如何增加。
2. 勾选“显示三角形边线”，观察每个四边形由两个三角形组成。
3. 切换“贴纹理”，比较相同形状加上石砖后的效果。
4. 调整“纹理尺寸”，观察砖块大小改变，而轮廓、路面宽度和垛口数量保持不变。
5. 点击墙身、路面或垛口，查看各表面的纹理、空间坐标与 UV。

## 代码阅读顺序

- `SIZE`：全部写死的示例尺寸，和游戏参数相互独立。
- `project()`：将地面位置和高度投到二维画面；采用方便观察的固定斜俯视投影。
- `buildFaces()` / `addBox()`：生成墙身、平台、女墙、垛口。
- `makeFace()`：为顶点指定 UV，决定纹理重复次数。
- `drawTexturedTriangle()`：用三组 UV 和画面坐标计算仿射变换，将重复图片绘入三角形。
- `drawFace()` / `render()`：绘制表面、模拟明暗、显示三角形边线。

纹理复制自 `Assets/Content/Maps/ArtV3/wall-masonry.png` 与 `wall-walkway.png`，保持原文件内容。
示例使用 Canvas 2D 解释纹理映射原理，不调用项目代码；Unity 中由 Mesh、材质、Shader 和 GPU 承担对应工作。
省略敌台、墙网、导航、精确遮挡、镜像采样及复杂裁切，只展示固定直墙。
